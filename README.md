## User Stories

- As a User , I want to view live countdown timers and latest bid so I know when the auction closes.
- As a User , I want to place a manual bid so I can compete for an item in real time.
- As a User , I want to set a maximum auto-bid limit so the system bids for me up to my top price.
- As a User , I want instant notifications if I am outbid/won the bid so I can react immediately.
- As a User, I want to list an item with photos, descriptions, and a starting price.
- As a User, I want to cancel, sell and choose the auction start and end dates/times.
- As a User, I want to view my items bidding history with their current high bidder for my the active items.
- As a User, I want to register and log in/sign up securely via email.
- As a User, I want to filter and search items by category, price, or status.

- As an Admin, I want to Verify Accounts To Allow them To Be a Seller .
- As an Admin, i want to view all bids and all users.
- As an Admin, i want to soft delete users.

For later:

- As a User, I want a secure checkout screen to pay for my won items quickly.
- As an Admin, I want to review and approve or reject new item listings to prevent fraud
- As an Admin, I want to ban abusive users or fake bidders to protect marketplace trust.
